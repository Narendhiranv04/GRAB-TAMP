# L2 living-room Region Ablation 1

Goal: **Place the refreshment tray on a suitable living-room surface within easy reach of the sofa.**

This report searches for a functional destination region rather than a
functional object. Geometry-only selects the rug, semantic-only selects the
undersized side table, and joint semantic–geometric verification selects the
coffee table. Every mode reuses the SHA-256-identified evidence listed in
`offline_region_ablation_evaluation.json`.

Open `presentation_report.html` for the complete visual report.

No FM parsing, planning, placement, robot execution, or TAMP execution occurs.
The successful output is only a verified destination-region handoff.
